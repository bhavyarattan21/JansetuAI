# JanSetuAI —

JanSetuAI is an AI-powered civic-service interface designed as a hackathon demo.

## Run locally

Requirements:
- Node.js 18+
- npm

Commands:

```bash
npm install
npm run dev
```

Deployed- (normally https://jansetu-ai-eight-theta.vercel.app/).

## Included demo flows

- Google-style login screen (demo only; no real Google credentials are collected)
- Post-login personalised welcome/onboarding page
- AI-style civic search
- Issue categories
- 3-step complaint flow
- Schemes & benefits section
- Local chat assistant with simple intent routing
- English / Hindi toggle
- Responsive dark civic-tech UI

## Production upgrade ideas

Connect the chat and issue classifier to an LLM API, add official government-service links, geolocation, authentication, database persistence, image upload, complaint tracking and multilingual speech.
